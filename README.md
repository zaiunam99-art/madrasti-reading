# مدرستي — منصة تعلم تفاعلية

منصة عربية متعددة الصفوف والمواد، تدير فيها الأسرة ملفات الأبناء ويتعلم كل طفل في مساحة مستقلة.

## الحالة الحالية
- واجهة تجريبية متجاوبة لولي الأمر والطالب.
- إدارة ملفات الأبناء محلياً في تطبيق ولي الأمر، وتخزين ملفات الطالب وتقدمه في مفاتيح مستقلة داخل تطبيق الطالب.
- محرك دروس أولي للقراءة والرياضيات للصف الأول، يضم 108 سجلات درس أولية مرتبة حسب الوحدات والفصول.
- أسئلة تفاعلية ومراجعات، مع نطق عربي عبر Web Speech API وصوت الجهاز عند توفره.
- يمكن تصدير ملف طفل واحد من تطبيق ولي الأمر واستيراده في تطبيق الطالب، ثم إعادة ملف التقدم إلى ولي الأمر يدوياً. لا توجد مزامنة تلقائية أو مصادقة سحابية.
- أساس PWA للتثبيت والعمل دون اتصال؛ تُحدّث ملفات المنهج من الشبكة وتُستخدم النسخة المخزنة عند انقطاعها.
- معاينة PDF محلية من جهاز ولي الأمر؛ لا يوجد رفع خادمي أو OCR تلقائي حالياً.
- Cloudflare Pages Functions لواجهة فحص الصحة، ومخطط D1 أولي غير مفعّل.

**تنبيه:** تطبيق ولي الأمر والطالب منفصلان في الواجهة والتخزين المحلي. ملفات النقل يدوية وغير مشفرة، ولا توجد مزامنة تلقائية أو مصادقة سحابية. واجهات الحساب وD1 غير مفعّلة في الواجهة الحالية؛ لا تستخدم بيانات أطفال حقيقية قبل إعداد المصادقة وقاعدة البيانات واختبارها.

## تشغيل النشر
اربط المستودع بـ Cloudflare Pages، واجعل مجلد الإخراج جذر المستودع. بعد ذلك أنشئ قاعدة D1 ونفّذ ملف الترحيل، ثم أضف binding باسم `DB` كما هو موضح في دليل النشر.

## المبادئ
- ولي الأمر يدير حساب الأسرة وملفات الأبناء.
- لكل طفل مساحة تعلم مستقلة.
- الاسم اختياري والتخصيص لا يغيّر المحتوى العلمي.
- الكتب المرفوعة تمر بمرحلة مراجعة قبل نشر الدروس المستخرجة.
- حماية بيانات الأسرة وعزل صلاحياتها شرط قبل الاستخدام الحقيقي.

## محرك الدروس الأولي
- `curriculum-runtime.js` يحمّل دروس القراءة والرياضيات للصف الأول من ملفات JSON داخل `curriculum/`، ويعرض أسئلة الاختيار والمراجعات المتاحة.
- يعمل دون API صوت مدفوع؛ يستخدم صوت المتصفح المحلي عند توفره.
- [تقرير حالة الربط وحدود النسخة](docs/current-prototype-audit.md).
- لا تزال المصادقة السحابية وD1 ورفع PDF وOCR والنشر والاختبار على الأجهزة غير مكتملة.

- [خطة التشغيل المجانية وحدود الخدمات](docs/free-only-architecture.md)


## حماية بيانات الأسرة

- تتوفر نسخة احتياطية محلية واستعادة لملفات الأسرة وسجل التقدم، مع التحقق من بنية الملف ومحاولة التراجع عند فشل الحفظ.
- النسخة الاحتياطية تحتوي بيانات ملفات الأبناء؛ احفظها في مكان خاص ولا تشاركها علناً.
