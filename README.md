# مدرستي — منصة تعلم تفاعلية

منصة عربية موحدة تبدأ بواجهة الطالب، وتضم إدارة ملفات الأسرة في قسم منفصل داخل التطبيق نفسه.

## الحالة الحالية
- واجهة طالب مباشرة، وقسم ولي أمر منفصل داخل التطبيق ومحمي برمز محلي.
- إدارة ملفات الأبناء محلياً من قسم ولي الأمر المدمج، وتخزين ملفات الطلاب وتقدمهم في مفاتيح محلية مستقلة.
- محرك دروس أولي للقراءة والرياضيات للصف الأول، يضم 108 سجلات درس أولية مرتبة حسب الوحدات والفصول.
- أسئلة تفاعلية ومراجعات وأنشطة عملية متخصصة لتتبع الأرقام وبناء الأنماط، مع نطق عربي عبر Web Speech API وصوت الجهاز عند توفره.
- شخصية معلم تعليمية كاملة الجسم برسوم SVG أصلية وحركة خفيفة للفم والجسم أثناء النطق؛ هي رسمة متجهية متحركة وليست نموذجاً ثلاثي الأبعاد حقيقياً.
- يمكن لولي الأمر إنشاء ملفات الأبناء وتعديلها وحذفها من القسم المدمج، وتصدير ملف طالب واحد أو نسخة احتياطية موحدة. لا توجد مزامنة تلقائية أو مصادقة سحابية.
- أساس PWA للتثبيت والعمل دون اتصال؛ يضم التخزين المسبق 25 ملف JSON للمناهج الحالية (نحو 431 كيلوبايت) بعد اكتمال التثبيت الأولي، ثم تُحدّث الملفات من الشبكة وتُستخدم النسخ المخزنة عند انقطاعها.
- لا يوجد رفع خادمي أو OCR تلقائي لملفات PDF حالياً.
- Cloudflare Pages Functions لواجهة فحص الصحة، ومخطط D1 أولي غير مفعّل.

**تنبيه:** رمز ولي الأمر قفل محلي محدود وليس مصادقة أمنية؛ لا يحمي البيانات من شخص يملك وصولاً تقنياً إلى الجهاز. ملفات النقل والنسخ الاحتياطية يدوية وغير مشفرة، ولا توجد مزامنة تلقائية أو مصادقة سحابية. واجهات الحساب وD1 غير مفعّلة في الواجهة الحالية؛ لا تستخدم بيانات أطفال حقيقية قبل إعداد المصادقة وقاعدة البيانات واختبارها.

## تشغيل النشر
اربط المستودع بـ Cloudflare Pages، واجعل مجلد الإخراج جذر المستودع. بعد ذلك أنشئ قاعدة D1 ونفّذ ملف الترحيل، ثم أضف binding باسم `DB` كما هو موضح في دليل النشر.

## المبادئ
- ولي الأمر يدير حساب الأسرة وملفات الأبناء.
- لكل طفل مساحة تعلم مستقلة.
- الاسم اختياري والتخصيص لا يغيّر المحتوى العلمي.
- الكتب المرفوعة تمر بمرحلة مراجعة قبل نشر الدروس المستخرجة.
- حماية بيانات الأسرة وعزل صلاحياتها شرط قبل الاستخدام الحقيقي.

## محرك الدروس الأولي
- `curriculum-runtime.js` يحمّل دروس القراءة والرياضيات للصف الأول من ملفات JSON داخل `curriculum/`، ويعرض أسئلة الاختيار والمراجعات المتاحة.
- يعمل دون API صوت مدفوع؛ يستخدم صوت المتصفح المحلي عند توفره.
- [تقرير حالة الربط وحدود النسخة](docs/current-prototype-audit.md).
- لا تزال المصادقة السحابية وD1 ورفع PDF وOCR والنشر والاختبار على الأجهزة غير مكتملة.

- [خطة التشغيل المجانية وحدود الخدمات](docs/free-only-architecture.md)


## حماية بيانات الأسرة

- تتوفر نسخة احتياطية محلية واستعادة لملفات الأسرة وسجل التقدم، مع التحقق من بنية الملف ومحاولة التراجع عند فشل الحفظ.
- النسخة الاحتياطية تحتوي بيانات ملفات الأبناء؛ احفظها في مكان خاص ولا تشاركها علناً.
