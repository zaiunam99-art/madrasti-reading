# عقد بيانات الدروس لمحرك العرض

هذه الوثيقة توحّد طريقة قراءة ملفات المناهج قبل ربطها بواجهة الطالب. لا تغيّر محتوى الكتب ولا تتطلب خدمة مدفوعة.

## 1. تحديد مجموعة الدروس
- ملفات الرياضيات القديمة للفصلين 1 و2 تستخدم `sequence`.
- ملفات الرياضيات للفصول 3–9 تستخدم `lessons`.
- ملف مراجعة الفصل الثاني يستخدم `review.questions` ولا يحتوي مصفوفة دروس.
- مراجعات الملفات الأحدث تستخدم `chapterReview.assessment`.
- ملفات القراءة تستخدم `lessons` و`unitReview.assessment`.

على المحرك أن يقرأ الحقل الموجود فعلياً، وألا يفترض أن كل الملفات لها البنية نفسها.

## 2. نص الشرح والصوت
- في ملفات الرياضيات القديمة: `teacherScript[]`، وكل عنصر يحتوي `role` و`text`.
- في ملفات القراءة والرياضيات الأحدث: `explanation[]` نصوص مرتبة، وقد توجد `example` أو `examples`.
- يجب تشغيل النصوص بالترتيب، مع إتاحة الإيقاف والإعادة، وعدم تشغيل فقرتين صوتيتين في الوقت نفسه.
- أدوار `teacherScript` مثل welcome وexplain وprompt وencourage توجه طريقة الإلقاء، ولا تُعرض للطفل كنص تقني.

## 3. توحيد الاختيارات والإجابات
- قد تكون الاختيارات نصوصاً أو أرقاماً أو كائنات مثل `{label, quantity}`.
- عند كون الاختيار كائناً، تُعرض `label` ويُقارن الجواب مع `label` أولاً، ثم `value` أو `quantity` بحسب نوع النشاط.
- لا تعتبر كل نشاط سؤال اختيار متعدد؛ توجد أنواع مثل create_pattern وsequence_completion وnumber_entry وsequence_order وread_syllables.
- في `sequence_order` تقارن الإجابة كمصفوفة مرتبة، لا كنص مفرد.
- إذا لم توجد `choices`، لا تنشئ اختيارات وهمية؛ اعرض إدخالاً أو تفاعلاً مناسباً لنوع النشاط.

## 4. التقييم والتقدم
- احتفظ بمعرف الدرس `id` ومعرف النشاط أو السؤال إن وجد.
- احسب المحاولات والإجابات الصحيحة على مستوى الطفل والمادة والدرس.
- لا تُسجل إكمال الدرس قبل إنهاء أنشطته المطلوبة.
- قيم `mastery.requiredCorrect` و`totalChecks` تُستخدم عندما تكون موجودة؛ وإلا استخدم إعدادات التقييم الخاصة بالدرس أو مراجعة الفصل.
- أظهر التغذية الراجعة عند توفر `feedbackCorrect` و`feedbackTryAgain`، وإلا استخدم عبارة تشجيع محايدة.

## 5. الصوت العربي
- استخدم Web Speech API أو صوت النظام المتاح فقط، مع فحص توفر صوت عربي على الجهاز.
- إذا لم يتوفر صوت عربي، أبق النص قابلاً للقراءة ولا توحِ بأن الصوت يعمل.
- يجب ألا تعتمد المنصة على مفتاح API أو خدمة مدفوعة لتشغيل الدروس الأساسية.
- لا تشغّل تلقائياً النشيد أو تسجل صوت الطفل؛ لا يوجد في البيانات الحالية ما يبرر ذلك.

## 6. الحماية والخصوصية
- ملفات JSON في المستودع هي محتوى دراسي عام وليست ملفات تعريف أطفال.
- لا تضع أسماء الأطفال أو نتائجهم أو بيانات أولياء الأمور في ملفات المنهج.
- لا تستخدم بيانات حقيقية للأطفال في النسخة التجريبية قبل تفعيل المصادقة وعزل الحسابات واختبار الحماية.

## 7. مبدأ التوافق
هذا العقد مواصفة تنفيذية فقط؛ لم يتم بعد تعديل واجهة الموقع أو ربط API به. يجب اختبار المحول على كل الملفات قبل تفعيل عرضه للأطفال.
