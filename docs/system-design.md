# تصميم منصة مدرستي — المواصفات المعتمدة

## 1. الرؤية والهدف
منصة تعليمية عربية تفاعلية متعددة الصفوف والمواد والمناهج، تعمل على الهواتف والأجهزة اللوحية والكمبيوتر. يدير ولي الأمر حساب الأسرة وملفات الأبناء، ولكل طفل مساحة تعلم مستقلة وبسيطة. تحوّل الكتب المعتمدة إلى مسارات دروس وأنشطة صوتية وبصرية، مع حفظ تقدم كل طفل بصورة منفصلة.

هذه الوثيقة تمثل المواصفات المعتمدة للتصميم، وليست ادعاءً بأن جميع الوظائف نُفذت أو نُشرت بعد.

## 2. القرارات التي اعتمدها المستخدم
- وتيرة الدروس: **مرنة**؛ يحدد ولي الأمر عدد الدروس أو وتيرتها لكل طفل ومادة، بدلاً من فرض درس واحد يومياً على الجميع.
- الصوت والشخصية: **اختيار ولي الأمر**؛ يختار الصوت والشخصية التعليمية المتاحة، ويمكن تخصيصهما لكل طفل، ومع إمكان التخصيص حسب المادة لاحقاً.
- التفاعل: **كامل**؛ صوت وصور ورسوم وألعاب وأنشطة وأسئلة واختبارات وتغذية راجعة.
- المناهج: **مكتبة جاهزة ورفع PDF معاً**.
- دخول الطفل: **مساحة مستقلة للطفل**، مع بقاء إدارة الحساب والإعدادات الحساسة بيد ولي الأمر.
- التقارير: **ملخص سريع وتقارير تفصيلية عند الطلب**.
- الأجهزة: تصميم متجاوب وسهل الاستخدام على الهاتف والكمبيوتر، مع مراعاة صغر سن المتعلمين.
- إدارة الحساب: ولي الأمر يدير ملفات أبنائه.

## 3. الأدوار والصلاحيات
### ولي الأمر
- إنشاء الحساب وتسجيل الدخول واستعادة الوصول.
- إضافة ملفات الأبناء وتعديلها وإيقافها أو حذفها.
- تحديد الصف والمنهج والمواد لكل طفل.
- اختيار الكتب من المكتبة أو رفع كتب PDF.
- تحديد عدد الدروس والوتيرة والأيام والوقت المفضل لكل مادة.
- اختيار الصوت والشخصية وإعدادات العرض.
- مشاهدة تقارير الأبناء وإدارة الوصول إلى مساحة الطفل.

### الطالب
- يدخل إلى مساحة تعلم مستقلة ومبسطة مرتبطة بملفه.
- يرى المواد والدروس المخصصة له فقط.
- ينفذ الأنشطة ويستمع للشرح ويشاهد الصور.
- يرى تقدمه وتشجيعه دون الوصول إلى إعدادات الأسرة أو ملفات أشقائه.
- لا يحتاج إلى إدارة حساب ولي الأمر أو بياناته.

### مدير المنصة (داخلي)
- إدارة مكتبة المناهج والصفوف والمواد وإصدارات الكتب.
- مراجعة المحتوى المستخرج والأنشطة قبل نشرها.
- إدارة الأصوات والشخصيات والأصول التعليمية.
- لا يستطيع ولي الأمر تعديل نسخة المنهج العامة المشتركة؛ يمكنه إدارة الكتب الخاصة بحسابه وفق الصلاحيات.

## 4. رحلة الاستخدام
1. يسجل ولي الأمر الدخول إلى حساب الأسرة.
2. ينشئ ملفاً لكل طفل: الاسم اختياري، والجنس اختياري للتخصيص البصري واللغوي فقط، والصف والمنهج.
3. يحدد المواد ويختار المناهج من المكتبة أو يرفع PDF.
4. يعرض النظام بيانات الكتاب المستخرجة: الوحدات والدروس وأرقام الصفحات، فيراجعها قبل اعتمادها.
5. يحدد ولي الأمر خطة التعلم: عدد الدروس أو الوتيرة لكل مادة، وأيام التعلم إن رغب.
6. يخصص الصوت والشخصية للطفل.
7. يدخل الطفل إلى مساحته المستقلة ويبدأ الدروس المتاحة له.
8. يحفظ النظام المحاولات والنتائج والإنجازات، وتظهر في لوحة ولي الأمر.

## 5. وحدات النظام الأساسية
- حساب الأسرة والمصادقة واستعادة الحساب.
- ملفات الأبناء والتبديل الآمن بينها.
- بوابة/مساحة تعلم مستقلة لكل طفل.
- مكتبة المناهج والصفوف والمواد وإصدارات الكتب.
- رفع PDF والتحقق من نوع الملف وحجمه وتخزينه.
- معالجة الكتب: OCR للصفحات المصورة، واستخراج النصوص والصور وتقسيم الوحدات والدروس وربطها بالصفحات.
- استوديو مراجعة للمحتوى المستخرج؛ لا ينشر OCR أو المحتوى المولد تلقائياً دون تدقيق واعتماد.
- مولد خطة الدرس: أهداف، تمهيد، شرح، أمثلة، نشاط، تقويم، وتغذية راجعة.
- محرك الأنشطة التفاعلية.
- مشغل صوت وشخصيات تعليمية قابلة للاختيار.
- إعداد وإدارة جدول التعلم المرن.
- سجل تقدم وتقارير وتحفيز.
- إعدادات الوصول وسهولة الاستخدام.

## 6. تجربة الدرس التفاعلي الكامل
يتكون الدرس، بحسب طبيعة المادة والصف، من:
1. ترحيب وتمهيد مناسب لعمر الطفل.
2. صورة أو مشهد أو سؤال يربط الدرس بخبرة الطفل.
3. شرح صوتي عربي متزامن مع عرض النص والصورة.
4. عرض المفاهيم أو الحروف أو الأمثلة خطوة بخطوة.
5. أنشطة تفاعلية مثل الاختيار من متعدد، المطابقة، ترتيب العناصر، الاستماع، القراءة، السحب والإفلات، وتحديد الصورة.
6. تدريب إضافي أو إعادة شرح عند الخطأ.
7. تقويم قصير مرتبط بأهداف الدرس.
8. نتيجة وتشجيع وتحديث سجل التقدم.

يختلف نوع النشاط وفق المادة والصف؛ فلا تُفرض لعبة غير مناسبة على درس أو مادة لا تلائمها.

## 7. محرك الجدولة المرنة
- يحدد ولي الأمر عدد الدروس أو الحد اليومي لكل طفل ولكل مادة.
- يمكن أن تكون الوتيرة يومية أو عدة أيام في الأسبوع أو حسب خطة يحددها ولي الأمر.
- يمكن تعديل الخطة أو إيقاف مادة مؤقتاً دون فقدان السجل السابق.
- يمكن السماح بمراجعة الدروس المكتملة في أي وقت.
- لا يفتح النظام الدروس وفق قاعدة ثابتة واحدة لجميع الأسر؛ بل يتبع الخطة المعتمدة لكل طفل.
- يحافظ على ترتيب الكتاب، ولا يتجاوز درساً سابقاً إلا إذا سمحت سياسة المادة أو إعداد ولي الأمر بذلك.
- تحفظ المنطقة الزمنية وموعد الاستحقاق لكل خطة.

## 8. الصوت والشخصيات
- يختار ولي الأمر من الأصوات والشخصيات المتاحة، ويمكن أن يختلف الاختيار من طفل إلى آخر.
- يدعم النظام صوتاً عربياً واضحاً، مع إعدادات سرعة الصوت وإعادته وكتمه.
- يمكن ربط صوت وشخصية مختلفين بمادة معينة إذا اختار ولي الأمر ذلك.
- تبدأ النسخة الأولى بالأصوات العربية الآلية المتاحة، مع إمكانية إضافة تسجيلات بشرية معتمدة لاحقاً.
- يمكن إضافة تدريب على قراءة الطالب بصوت عالٍ في مرحلة لاحقة، بعد اختبار دقة التعرف على الكلام العربي وتوضيح حدود التقييم.
- الاسم اختياري؛ عند عدم إدخاله تستخدم المنصة مخاطبة عامة.
- الجنس اختياري ويستخدم فقط لصيغة المخاطبة أو اختيار الشخصية، ولا يغير المحتوى العلمي أو مستوى الصعوبة.
- تستخدم رسومات تعليمية أصلية أو مرخصة، ولا يلزم رفع صورة شخصية للطفل.

## 9. المناهج ومكتبة الكتب
### المكتبة الجاهزة
- تصفح المناهج حسب الدولة/الجهة، الصف، المادة، والسنة أو الإصدار.
- عرض اسم الكتاب ونسخته وحالته.
- ربط عدة كتب بمادة أو صف عند الحاجة.

### رفع PDF
- رفع كتاب من حساب ولي الأمر.
- التحقق من نوع الملف وحجمه وفحصه.
- حفظه في مساحة ملفات آمنة.
- استخراج الصفحات والنصوص والصور، بما في ذلك OCR للكتب المصورة.
- اقتراح الوحدات والدروس مع أرقام الصفحات.
- إظهار شاشة مراجعة قبل اعتماد التقسيم والمحتوى.
- تمييز نص الكتاب الأصلي بوضوح عن الشرح والأنشطة المضافة.
- احترام حقوق استخدام الكتب وعدم إتاحتها للعامة دون إذن.

## 10. الدخول المستقل للطفل
- لكل طفل مدخل واضح إلى مساحة التعلم الخاصة به.
- يمكن أن تكون آلية الدخول برمز طفل أو PIN يفعّله ولي الأمر، أو اختيار ملف الطفل من جهاز الأسرة؛ يحدد التصميم النهائي آلية آمنة وسهلة.
- لا يحتاج الطفل إلى الاطلاع على بريد ولي الأمر أو كلمة مروره.
- يستطيع ولي الأمر إيقاف مدخل الطفل أو إعادة ضبط رمزه.
- يمنع النظام الوصول إلى ملفات الأشقاء أو التقارير أو الإعدادات الإدارية.
- لا يُسمح بتغيير معرّف الطفل في الرابط للوصول إلى ملف آخر؛ تفرض الصلاحيات في الخادم وقاعدة البيانات.

## 11. التقارير والمتابعة
### ملخص سريع
- نسبة الإنجاز لكل طفل.
- الدروس المكتملة والمتبقية.
- ملخص أداء المواد.
- آخر نشاط تعليمي.

### تقرير تفصيلي عند الطلب
- نتائج الأنشطة والاختبارات.
- المحاولات والتقدم عبر الزمن.
- المهارات المتقنة والمهارات التي تحتاج إلى مراجعة.
- الدروس التي أعيدت.
- الوقت التعليمي التقريبي.
- مقارنة تقدم الطفل بنفسه عبر الفترات، لا ترتيب الأطفال أو إحراجهم بمقارنات.

## 12. واجهة الهاتف والكمبيوتر
- تصميم عربي RTL متجاوب يبدأ من الهاتف ثم يتوسع للشاشات الكبيرة.
- أزرار كبيرة وواضحة تناسب الأطفال، ونصوص قصيرة ومفردات سهلة.
- تقليل القوائم المعقدة داخل مساحة الطفل.
- لوحة ولي الأمر أكثر تفصيلاً، منفصلة بصرياً عن واجهة الطفل.
- دعم الأجهزة اللوحية واللمس ولوحة المفاتيح.
- إعدادات حجم الخط والتباين وتشغيل الصوت وإيقافه وتقليل الحركة.
- حفظ التقدم عند التنقل بين الصفحات، وإظهار حالة الاتصال أو تعذر المزامنة بوضوح.
- إمكانية تطوير نسخة PWA قابلة للإضافة إلى الشاشة الرئيسية لاحقاً.

## 13. نموذج البيانات المقترح
- parents: حساب ولي الأمر وبيانات المصادقة.
- children: id, parent_id, display_name, gender_preference, grade_id, avatar_id, child_access_method, created_at.
- child_access_credentials: بيانات اعتماد الطفل المجزأة/المشفرة حسب آلية الدخول، وحالة التفعيل وإعادة الضبط.
- grades: الصفوف الدراسية.
- curricula: الدولة/الجهة/إصدار المنهج.
- subjects: المواد.
- books: curriculum_id, grade_id, subject_id, title, pdf_object_key, version, status, owner_parent_id.
- units: book_id, title, sequence, page_start, page_end.
- lessons: unit_id, title, sequence, source_pages, lesson_content, audio_key, review_status.
- activities: lesson_id, type, prompt, options, answer_key, feedback.
- voice_profiles: اسم الصوت واللغة والخصائص ومصدر الصوت.
- child_preferences: child_id, voice_profile_id, avatar_id, speech_rate, accessibility_preferences.
- learning_plans: child_id, subject_id, lessons_per_day, frequency, weekdays, start_date, timezone, enabled.
- progress: child_id, lesson_id, status, score, attempts, completed_at.
- activity_attempts: child_id, activity_id, response, result, attempted_at.
- daily_assignments: child_id, lesson_id, assigned_date, due_at, status.
- assets: صور ورسوم وملفات صوت مرتبطة بالمحتوى.
- audit_events: أحداث إدارية وأمنية لازمة للتدقيق دون تخزين أسرار أو كلمات مرور.

كل سجل خاص بطفل يجب أن يرتبط بولي الأمر، وتُفرض صلاحيات الوصول على الخادم وقاعدة البيانات لا في واجهة المتصفح فقط.

## 14. البنية التقنية المقترحة
- الواجهة: تطبيق ويب عربي RTL متجاوب.
- النشر: Cloudflare Pages.
- الخلفية: Cloudflare Workers API.
- قاعدة البيانات: Cloudflare D1 لحسابات الأسرة والطلاب والمناهج والخطط والتقدم.
- الملفات: Cloudflare R2 لملفات PDF والصور والصوت.
- المصادقة: جلسات آمنة عبر الخادم، كلمات مرور مجزأة، حماية من محاولات الدخول، واستعادة الحساب.
- معالجة الكتب: مهام خلفية لاستخراج الصفحات وOCR وإنشاء مسودات الدروس.
- الصوت: واجهة موحدة تسمح بتبديل مزود الصوت أو إضافة تسجيلات معتمدة.
- النسخ الاحتياطي والمراقبة: نسخ دورية وسجلات أخطاء لا تتضمن كلمات المرور أو البيانات الحساسة.

## 15. الخصوصية والأمان
- ولي الأمر هو صاحب حساب الأسرة والمسؤول عن ملفات أبنائه.
- لا يستطيع طفل الاطلاع على ملف طفل آخر.
- لا تعرض أسماء الأطفال أو نتائجهم علناً.
- جمع الحد الأدنى من البيانات؛ لا حاجة إلى تاريخ ميلاد كامل أو صورة شخصية.
- روابط الملفات الخاصة مؤقتة وموقعة.
- تحديد أنواع الملفات وحجمها وفحص الملفات المرفوعة.
- توضيح ما إذا كانت خدمة الصوت أو الذكاء الاصطناعي ترسل بيانات إلى مزود خارجي، وعدم إرسال بيانات تعريفية بالطفل دون ضرورة وموافقة واضحة.
- توفير سياسة واضحة للاحتفاظ بالبيانات وحذف الحساب والملفات.
- تشفير الاتصال وحماية الأسرار ومفاتيح الخدمات وعدم وضعها في كود الواجهة.

## 16. مراحل التنفيذ
1. **النموذج المرئي المتجاوب:** صفحة دخول ولي الأمر، لوحة الأسرة، ملفات الأبناء، مدخل الطفل، اختيار المناهج، شاشة درس تفاعلي.
2. **الهوية والصلاحيات:** تسجيل دخول حقيقي، دخول مستقل للطفل، قاعدة بيانات، عزل بيانات الأسر والأبناء.
3. **الخطط المرنة والتقارير:** تحديد الوتيرة لكل مادة، الملخص والتقرير التفصيلي.
4. **مكتبة المناهج:** الكتب الجاهزة ورفع PDF والتخزين الآمن.
5. **استوديو تجهيز الدروس:** OCR وتقسيم الوحدات ومراجعة المحتوى واعتماده.
6. **الصوت والتفاعل:** اختيار الأصوات والشخصيات، الألعاب، الأنشطة، القراءة والاستماع.
7. **اختبار وإطلاق تدريجي:** اختبار الهواتف والكمبيوتر، سهولة الاستخدام، الأمان، النسخ الاحتياطي ثم النشر.

## 17. حدود النسخة الحالية
ملف HTML السابق نموذج أولي محلي فقط. لا يحتوي بعد على تسجيل دخول حقيقي أو قاعدة بيانات أو رفع PDF سحابي أو صلاحيات آمنة أو OCR أو جدولة مرنة مكتملة أو تقارير حقيقية. لا يستخدم التخزين المحلي في المتصفح بديلاً عن قاعدة بيانات لحسابات أطفال حقيقية.
