# تصميم منصة مدرستي

## 1. الهدف
منصة تعلم تفاعلية متعددة الصفوف والمواد والمناهج. يدير ولي الأمر حسابه وملفات أبنائه، ويتعلم كل طفل من خلال واجهة مناسبة لعمره مع حفظ تقدمه بصورة مستقلة.

## 2. الأدوار والصلاحيات
- ولي الأمر: إنشاء حساب، إضافة الأبناء وتعديل ملفاتهم، اختيار الصف والمنهج والمواد، متابعة التقدم، وإدارة الكتب المضافة.
- الطالب: يدخل إلى مساحة تعلم مبسطة مرتبطة بملفه، ولا يستطيع الاطلاع على ملفات أشقائه أو إعدادات الحساب.
- مدير المنصة (داخلي): إدارة المناهج العامة ومراجعة المواد المنشورة. لا يملك ولي الأمر صلاحية تعديل محتوى المنهج العام.

## 3. رحلة الاستخدام
1. يفتح ولي الأمر المنصة ويسجل الدخول.
2. ينشئ ملفاً لكل طفل: الاسم (اختياري)، الجنس (اختياري ويستخدم فقط لاختيار صيغة المخاطبة/الشخصية)، الصف، الدولة/المنهج.
3. يختار الطفل من لوحة الأسرة.
4. تعرض المنصة المواد المتاحة لذلك الصف، ثم الوحدات والدروس حسب ترتيب الكتاب.
5. يظهر درس اليوم فقط افتراضياً، مع إمكانية مراجعة الدروس السابقة المكتملة.
6. بعد إتمام النشاط، يسجل النظام النتيجة والوقت والمحاولات ويحدّث لوحة المتابعة.

## 4. وحدات النظام
- حساب ولي الأمر والمصادقة واستعادة الحساب.
- ملفات الأبناء والتبديل الآمن بينها.
- مكتبة المناهج والصفوف والمواد والكتب.
- رفع ملفات PDF والتحقق من نوعها وحجمها وتخزينها.
- معالجة الكتاب: OCR للصفحات المصورة، استخراج النصوص والصور، تقسيم الوحدات والدروس، وربط كل جزء برقم الصفحة.
- محرر مراجعة للمحتوى المستخرج قبل نشره؛ لا ينشر المحتوى الآلي تلقائياً دون مراجعة.
- مولّد خطط الدروس: أهداف، تمهيد، شرح، مثال، نشاط، سؤال تقويمي، وتغذية راجعة.
- محرك أنشطة: اختيار من متعدد، مطابقة، ترتيب، استماع، قراءة، وسحب وإفلات.
- الصوت: نطق عربي آلي كحل أولي، مع إمكانية إرفاق تسجيلات معتمدة لكل درس.
- التقدم والتقارير والتحفيز.
- إعدادات الوصول: حجم الخط، تباين الألوان، تشغيل/إيقاف الصوت، وتقليل الحركة.

## 5. تخصيص تجربة الطفل
- الاسم اختياري؛ عند عدم إدخاله تستخدم المنصة عبارة ترحيب عامة.
- الجنس اختياري ولا يؤثر في المحتوى أو مستوى الصعوبة؛ يستخدم فقط لاختيار ضمير المخاطبة أو شكل الشخصية.
- رسومات تعليمية أصلية مع خيار شخصية محايدة.
- لا تستخدم الصور الشخصية للطفل ولا تُنشئ صوراً واقعية له.
- يمكن لولي الأمر تغيير هذه الخيارات في أي وقت.

## 6. نموذج البيانات المقترح
- parents: هوية ولي الأمر وبيانات تسجيل الدخول.
- children: id, parent_id, display_name, gender_preference, grade_id, avatar_id, created_at.
- grades: الصفوف الدراسية.
- curricula: الدولة/الجهة/إصدار المنهج.
- subjects: المواد.
- books: curriculum_id, grade_id, subject_id, title, pdf_object_key, version, status.
- units: book_id, title, sequence, page_start, page_end.
- lessons: unit_id, title, sequence, source_pages, lesson_content, audio_key, review_status.
- activities: lesson_id, type, prompt, options, answer_key, feedback.
- progress: child_id, lesson_id, status, score, attempts, completed_at.
- daily_assignments: child_id, lesson_id, assigned_date.
- assets: صور ورسوم وملفات صوت مرتبطة بالمحتوى.

كل سجل خاص بطفل يجب أن يكون مرتبطاً بولي الأمر، وتُفرض صلاحيات الوصول على الخادم وقاعدة البيانات لا في واجهة المتصفح فقط.

## 7. قواعد التعليم
- ترتيب الدروس يتبع ترتيب الكتاب المعتمد ولا يعاد ترتيبه تلقائياً.
- درس يومي واحد لكل طفل ولكل مادة مفعّلة، وفق المنطقة الزمنية المختارة.
- لا يُفتح درس جديد قبل موعده، مع السماح بمراجعة الدروس السابقة.
- لا تُعرض إجابة السؤال قبل المحاولة، والتغذية الراجعة مشجعة.
- كل نشاط مرتبط بهدف تعليمي واضح، ويُسجل التقدم لكل طفل على حدة.
- نصوص الكتاب الأصلية تبقى مميزة عن الشرح والأنشطة المضافة.
- أي نص مستخرج بالـ OCR يمر بمراجعة بشرية قبل اعتماده.

## 8. البنية التقنية المقترحة
- الواجهة: تطبيق ويب متجاوب RTL يعمل على الهاتف والكمبيوتر، ويمكن تحويله لاحقاً إلى PWA.
- النشر: Cloudflare Pages للواجهة.
- الخلفية: Cloudflare Workers API.
- قاعدة البيانات: Cloudflare D1 لعلاقات الحسابات والطلاب والمناهج والتقدم.
- الملفات: Cloudflare R2 لملفات PDF والصور والصوت.
- المصادقة: جلسات آمنة عبر الخادم، كلمات مرور مجزأة، حماية من محاولات الدخول، واستعادة الحساب.
- المعالجة: مهمة خلفية لاستخراج صفحات PDF وOCR وبناء مسودة الدروس.
- النسخ الاحتياطي والمراقبة: نسخ دورية لقاعدة البيانات، وسجلات أخطاء لا تتضمن كلمات المرور أو بيانات حساسة.

## 9. الخصوصية والأمان
- حساب ولي الأمر هو المالك الوحيد لملفات أطفاله.
- منع الوصول إلى طفل بتغيير المعرّف في الرابط أو الطلب.
- روابط الملفات الخاصة تكون مؤقتة وموقعة.
- عدم إظهار أسماء الأطفال أو نتائجهم علناً.
- جمع الحد الأدنى من البيانات؛ لا حاجة لتاريخ ميلاد كامل أو صورة شخصية.
- حذف الحساب وملفات الأطفال وفق سياسة واضحة.
- تحديد أنواع الملفات وحجمها وفحص الملفات المرفوعة.
- لا تُرسل بيانات الأطفال إلى خدمات خارجية إلا عند الضرورة وبموافقة واضحة.

## 10. مراحل التنفيذ
1. النموذج المرئي: لوحة ولي الأمر، ملفات الأبناء، اختيار الطالب، عرض المناهج، نموذج درس تفاعلي.
2. الخلفية: مصادقة حقيقية، قاعدة بيانات، صلاحيات، وحفظ سحابي للتقدم.
3. مكتبة الكتب: رفع PDF، تخزينه، واستخراج الصفحات والنصوص والصور.
4. استوديو إعداد الدروس: مراجعة OCR وتقسيم الوحدات وإنشاء الأنشطة واعتمادها.
5. الصوت والتفاعل: أصوات عربية، ألعاب، قراءة واستماع، وإتاحة الاستخدام.
6. التقارير والإطلاق: تقارير الأسرة، اختبارات الاستخدام، النسخ الاحتياطي، ثم النشر.

## 11. ما هو غير مكتمل في النموذج الحالي
ملف HTML الحالي نموذج أولي محلي فقط. لا يحتوي بعد على تسجيل دخول حقيقي أو قاعدة بيانات أو رفع PDF سحابي أو صلاحيات آمنة أو معالجة OCR. لا يجوز استخدام التخزين المحلي في المتصفح كبديل عن قاعدة بيانات لحسابات أطفال حقيقية.
