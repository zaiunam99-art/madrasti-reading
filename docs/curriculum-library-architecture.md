# بنية مكتبة المناهج في مدرستي التفاعلية

تاريخ الإعداد: 2026-11-28  
النطاق الحالي: الصف الأول الابتدائي العراقي، القراءة والرياضيات، إصدارا 2025-2026 المرفوعان للمشروع.

## 1. الهدف

تحويل ملفات المناهج من مجموعة ملفات منفصلة إلى مكتبة منظمة قابلة للتوسع والتدقيق. المكتبة تفصل بين:
- **المصدر الأصلي:** ملف الكتاب أو الدليل كما استلمه المشروع، ولا يُستبدل بالمحتوى المعاد صياغته.
- **الفهرس:** بيانات الصف والمادة والطبعة والوحدات أو الفصول ونطاق الصفحات وروابط ملفات الدروس.
- **محتوى الدروس:** صياغة تعليمية منظمة مرتبطة بموضعها في المصدر.
- **حالة الجودة:** حالة إعداد ومراجعة واعتماد مستقلة عن صلاحية JSON أو نجاح الاختبارات البرمجية.

## 2. البنية الحالية

```text
curriculum/
  grade-1/
    reading-2025-2026/
      units-index.json
      lessons/
        preparatory-unit.json
        unit-01-my-family.json
        ...
    math-2025-2026/
      chapters-index.json
      lessons/
        chapter-01-...
        ...
docs/
  curriculum-library-architecture.md
  grade-1-scientific-pedagogical-review.md
```

الفهرسان الحاليان غير متماثلين تماماً، لذلك يجب على الأدوات دعم الصيغتين:
- القراءة: `units`، و`bookPages`، ورابط مفرد `lessonFile`.
- الرياضيات: `chapters`، و`pdfPages`، ومصفوفة `lessonFiles`.
- ملفات الدروس تستخدم حالياً `lessons`، وقد تقبل أداة التحقق `sequence` للتوافق مع صيغ أقدم.

لا تُعد أسماء الحقول المختلفة خطأً بحد ذاتها؛ الخطأ هو غياب البيانات المطلوبة أو عدم صلاحيتها أو انقطاع الرابط.

## 3. الحد الأدنى لبيانات المصدر والفهرس

يجب أن يصف كل فهرس:
- البلد والصف والمادة والسنة الدراسية والطبعة.
- عنوان المصدر وعدد صفحاته متى كان معروفاً.
- طريقة الحصول على المصدر وحالة التحقق منه.
- الوحدات أو الفصول بترتيب واضح وعنوان ونطاق صفحات صحيح.
- رابطاً واحداً أو أكثر لملفات الدروس التابعة للمجموعة.
- ملاحظات توضح أي حدود أو عدم يقين في أرقام الصفحات.

لا تُخترع بيانات الطبعة أو عدد الصفحات أو حالة الرسمية. إذا لم تُعرف، تسجل بوضوح على أنها غير متحققة.

## 4. بطاقة الدرس

الحقول الأساسية:
- `id`: معرف فريد وثابت.
- `order`: ترتيب الدرس داخل ملفه.
- `title`: عنوان واضح.
- `bookPages`: نطاق صفحات المصدر.
- `objective`: هدف تعليمي قابل للملاحظة.
- `explanation`: شرح متدرج بلغة عربية فصحى مناسبة للصف.
- `examples`: أمثلة صحيحة مرتبطة بالهدف عند الحاجة.
- `activities`: ممارسة تعليمية؛ ويجب تحديد ما إذا كانت قابلة للتقييم الآلي أم استجابة مفتوحة.
- `quiz`: أسئلة تقيس الهدف، مع إجابات مرجعية عندما يكون السؤال مغلقاً.
- بيانات اختيارية مثل المفردات والتشجيع وتهيئة الصوت.

تُحفظ صياغة الدروس الأصلية منفصلة عن صفحات الكتاب. ولا تُنسخ نصوص محمية طويلة أو أناشيد من المصدر.

## 5. حالات سير العمل

| الحالة | معناها | شرط الانتقال |
|---|---|---|
| مسودة | بدأ إعداد الدرس أو فهرسته | اكتمال الحقول الأساسية وربط المصدر |
| قيد المراجعة | جاهز للتدقيق | مراجعة علمية وتربوية وتدقيق الإجابات |
| معتمد | اجتاز المراجعة المحددة | وجود مصدر وصفحات وقرار مراجعة موثق |
| يحتاج تحديثاً | تغير المصدر أو ظهرت ملاحظة مؤثرة | إعادة المراجعة قبل الاعتماد التالي |

لا تعني عبارة `initial_lessons_created` أو `lesson_content_created` أن الدرس معتمد نهائياً. هذه أوصاف لحالة إنشاء المحتوى فقط.

## 6. بوابات الجودة

### أ. بوابة المصدر
- المصدر معروف ومحدد الطبعة.
- نطاق الصفحات داخل عدد صفحات المصدر.
- روابط الدروس موجودة ويمكن فتحها وقراءة JSON الخاص بها.
- لا توجد وحدات أو فصول مكررة أو خارج الترتيب.

### ب. البوابة العلمية
- الهدف والشرح والأمثلة متسقة.
- كل إجابة مرجعية صحيحة ويمكن تبريرها.
- لا توجد أسئلة ملتبسة أو خيارات متعددة صحيحة دون قصد.
- المصطلحات والرموز والأمثلة متوافقة مع مستوى الصف.

### ج. البوابة التربوية
- ينتقل الدرس من المألوف إلى المجرد ومن السهل إلى الأصعب.
- تتنوع الممارسة ولا تتحول إلى تكرار آلي للأسئلة.
- تناسب كمية النص والتعليمات عمر المتعلم.
- تتيح الأنشطة المفتوحة للطفل التعبير دون فرض إجابة واحدة غير لازمة.

### د. البوابة التقنية
- كل نوع نشاط مدعوم فعلياً بمحرك التطبيق.
- السؤال والإجابة والتغذية الراجعة تعمل بصورة صحيحة.
- الصوت التلقائي لا يكرر القراءة ولا يتداخل مع السؤال السابق.
- يحفظ التقدم ويستعيده بصورة صحيحة.

نجاح فحص JSON أو CI لا يثبت وحده اجتياز البوابات العلمية والتربوية أو التشغيلية.

## 7. مخرجات التدقيق

ينبغي أن ينتج فحص المكتبة تقريراً يميز بين:
- أخطاء مانعة: JSON غير صالح، رابط مكسور، معرف مكرر، إجابة مغلقة غير موجودة في الخيارات، أو نطاق صفحات يتجاوز المصدر.
- تحذيرات جودة: غياب هدف أو شرح أو نشاط أو اختبار أو صفحات مصدر.
- مؤشرات إحصائية: عدد الفهارس والمجموعات والملفات والدروس والأنشطة والأسئلة.
- حالة المراجعة البشرية: غير مراجع، قيد المراجعة، أو معتمد مع مرجع المراجعة.

يجب ألا تتحول التحذيرات تلقائياً إلى اعتماد أو إلى تعديل للمحتوى.

## 8. التوسع إلى بقية الصفوف والمواد

يُضاف كل صف ومادة وطبعة في مسار مستقل، ولا تخلط طبعات السنوات المختلفة في فهرس واحد. يظل إصدار 2025-2026 مرجعاً مؤقتاً فقط عندما لا يتوفر إصدار 2026-2027 موثق. عند وصول طبعة أحدث، تُضاف كإصدار مستقل ثم تُقارن قبل تغيير الإصدار النشط.

## 9. خطة التنفيذ

1. تثبيت هذا العقد التنظيمي للمكتبة.
2. فحص جميع روابط فهارس الصف الأول ومحتوى الدروس والحقول المطلوبة.
3. تطوير أداة التحقق لتنتج تقرير جودة واضحاً مع أخطاء وتحذيرات منفصلة.
4. إعداد سجل مراجعة علمية وتربوية للدروس، دون وسم المحتوى بأنه معتمد قبل المراجعة.
5. لاحقاً، بناء واجهة إدارة للمكتبة بعد استقرار نموذج البيانات وأداة التحقق.

## 10. حدود موثوقية البيانات الحالية

- فهرسا القراءة والرياضيات في المستودع يصفان إصدارين من 2025-2026، ولا يثبتان وحدهما أن الإصدار الرسمي الكامل 2026-2027 قد تم التحقق منه.
- بعض محتوى الدروس صيغ تعليمياً بصورة أصلية اعتماداً على معاينة الكتاب، وليس نسخاً حرفياً منه.
- وجود صفحات مصدر أو رابط ملف لا يعني أن كل جملة أو إجابة خضعت لمراجعة بشرية نهائية.
- لا تُعلن المكتبة مكتملة حتى يُستكمل جرد الروابط ومراجعة الدروس واختبارها داخل التطبيق.
