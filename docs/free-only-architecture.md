# خطة تشغيل مجانية دون التزام مالي

## المبدأ
يجب أن تعمل النسخة الأساسية دون بطاقة مصرفية أو اشتراك أو تجربة مجانية مدفوعة. لا نفعّل أي خدمة تطلب وسيلة دفع، ولا نسمح بالترقية التلقائية أو تجاوز الحصص المجانية.

## ما يمكن تشغيله محلياً أو كملفات ثابتة
- ملفات HTML وCSS وJavaScript وJSON للمناهج.
- GitHub لحفظ الشيفرة والمحتوى البنيوي.
- PWA وService Worker لتخزين الملفات التي زارها المستخدم مؤقتاً.
- Web Speech API وصوت الجهاز عند توفر صوت عربي.
- رسومات SVG أصلية وشخصية كرتونية بسيطة.
- مدقق JSON يعمل محلياً باستخدام Node.js دون مكتبات خارجية.
- OCR مفتوح المصدر عند تشغيله على حاسوب محلي، مع مراجعة بشرية للنتائج.

## الخدمات السحابية الاختيارية
قد تسمح بعض الخطط المجانية باستضافة الملفات الثابتة أو قاعدة بيانات صغيرة، لكن حدودها وشروطها قابلة للتغيير. قبل ربط أي خدمة:
1. تحقق من أنها لا تطلب بطاقة أو تفعيل تجربة.
2. راجع حد التخزين والطلبات وحجم الملفات.
3. أوقف المزامنة أو الرفع إذا اقترب الاستخدام من الحد المجاني.
4. لا تضف وسيلة دفع ولا تفعّل تجاوز الحصة.
5. احتفظ بخيار التشغيل المحلي دون تلك الخدمة.

## ما لا نعد به
- لا يوجد تخزين سحابي غير محدود مجاناً.
- لا يوجد صوت عربي موحد مضمون على كل الأجهزة.
- لا يمكن ضمان بقاء خطة مجانية لدى أي مزود إلى الأبد.
- لا يجوز وصف المشروع بأنه مجاني بالكامل إذا أضيفت خدمة مدفوعة أو تتطلب بطاقة.

## وضع المشروع الآن
- المحتوى والفهرسة محفوظان في GitHub.
- محرك الدروس الأولي يعمل من ملفات JSON الثابتة عند استضافتها في نفس الموقع.
- التقدم التجريبي محلي في المتصفح.
- قاعدة D1 غير مهيأة: `wrangler.toml` ما زال يحتوي على قيمة تعريف قاعدة بيانات شكلية.
- لا يوجد رفع PDF أو OCR سحابي.
- لم يتم نشر نسخة جديدة من هذا التحديث.

## قرار آمن
إلى أن يتم اختبار الاستضافة وقاعدة البيانات ضمن حدود واضحة، نعتمد النسخة الثابتة والتقدم المحلي للتجربة فقط. لا تستخدم بيانات شخصية حقيقية للأطفال في النسخة التجريبية.
