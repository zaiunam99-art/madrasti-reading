# تدقيق الواجهة التجريبية بعد ربط محرك المنهج

تاريخ التحديث: 2026-11-27
الملفات التي تمت مراجعتها: `index.html`, `curriculum-runtime.js`, `sw.js`

## ما أُنجز في هذه الدفعة
- أضيف `curriculum-runtime.js` لقراءة فهارس القراءة والرياضيات للصف الأول وفتح ملفات الدروس الفعلية بدلاً من مجموعة الأسئلة الثابتة.
- يدعم المحرك اختلاف البنية بين `lessons` و`sequence`، ويقرأ الشرح من `explanation` أو `teacherScript`.
- يجمع أسئلة الأنشطة والاختبارات التي لها خيارات وإجابة محددة، ويعرض مراجعات الوحدات والفصول عند وجودها.
- يوضح الصفحات والإصدار مع عنوان الدرس، ويعرض رسالة واضحة عند عدم وجود منهج مدعوم بدلاً من اختلاق محتوى.
- أضيفت شخصية معلم كرتونية مبسطة مع حركة فم تقريبية أثناء نطق المتصفح، وزرا تشغيل/إعادة وإيقاف الصوت. تظل جودة الصوت رهناً بالأصوات العربية المثبتة في الجهاز.
- أُضيف ملف المحرك إلى غلاف التخزين المؤقت في Service Worker مع تغيير إصدار الذاكرة المؤقتة إلى v2.
- تم تعديل واجهة الطالب لفتح قائمة الدروس حسب المادة.

## حدود لم تُحل بعد
- ملفات الأسرة والتقدم ما زالت محفوظة في `localStorage`؛ لا يوجد ربط تشغيلي مثبت بقاعدة D1 أو المصادقة.
- واجهات API وقاعدة البيانات موجودة جزئياً في المستودع، لكن لم تُربط بالواجهة ولم تُختبر في بيئة منشورة.
- رفع PDF ما زال اختيار ملف محلياً فقط؛ لا يوجد رفع آمن أو OCR أو محرر اعتماد للمحتوى.
- المحرك يقيم الاختيار من متعدد والإجابة العددية وترتيب العناصر عندما تكون الإجابة المرجعية معرفة في ملف الدرس. الأنشطة المفتوحة مثل الإجابة الشفهية ووصف الصور لا تزال للعرض والتدريب، ولا تُقيّم آلياً. أضيفت مراجعات الوحدات والفصول حيث تتوفر أسئلة مراجعة منظمة.
- الشخصية كرتونية أولية، وليست رسماً متحركاً متقدماً أو مزامنة شفاه دقيقة.
- المحتوى المدعوم في المحرك حالياً هو كتابا القراءة والرياضيات للصف الأول بإصدار 2025–2026 فقط. إصدار قراءة 2026–2027 لم يُدمج لأن المتاح الرسمي الذي تم العثور عليه جزئي ويحتاج تنزيل وفحص مستقل.
- لم يتم إجراء اختبار متصفح آلي أو اختبار فعلي على هاتف Android في هذه الدفعة، ولم يتم نشر الموقع.

## فحوص الملفات
- ملفات القراءة السبعة: JSON صالح، وبها 47 درساً أولياً ومراجعات وحدات.
- ملفات الرياضيات الثلاثة عشر: JSON صالح، وبها 61 درساً أولياً ومراجعات بحسب الملفات.
- جميع مسارات ملفات الدروس التي أشار إليها الفهرسان تم التحقق منها في GitHub.
- مجموع الدروس الأولية المفهرسة: 108 دروس، قبل احتساب المراجعات.

## خطوات لازمة قبل أي استخدام حقيقي
1. اختبار الواجهة المنشورة على متصفحات Android وChrome وFirefox، والتحقق من مسارات الملفات والصوت.
2. بناء جلسة ولي أمر حقيقية وربط واجهات API بعد إعداد D1 وبيئة آمنة.
3. اختبار عزل بيانات طفلين وأسرتين، ومنع الوصول إلى سجل طفل من حساب آخر.
4. إكمال أنشطة السحب والترتيب والإجابة المفتوحة والمراجعات.
5. إنشاء تدفق رفع PDF خاص ومعالجة OCR ومراجعة بشرية قبل اعتماد أي درس.
6. إكمال بقية الصفوف والطبعات بعد تنزيل الكتب ومراجعتها صفحة بصفحة.

## قرار النشر
التعديلات محفوظة في GitHub على الفرع الافتراضي فقط. لم يتم نشر نسخة جديدة إلى Cloudflare Pages أو AppDeploy، ولا يُعد المشروع جاهزاً للإنتاج أو للاحتفاظ ببيانات أطفال حقيقية.

### تحديث فني لاحق — 2026-11-27

- عولج توافق أسئلة المنهج: المحرك يقرأ الآن `choices` و`options`، ولا يحصر أسئلة الدرس بالاختيار المتعدد فقط.
- أضيف دعم إجابة الأعداد عبر حقل إدخال، ودعم ترتيب العناصر عبر قوائم اختيار مرتبة، مع مقارنة الأرقام العربية والهندية.
- أضيف سير عمل GitHub Actions مجاني يعمل عند الدفع إلى `main` أو فتح طلب دمج أو تشغيله يدوياً؛ يفحص صياغة JavaScript ثم يتحقق من ملفات JSON والفهارس.
- لم تصلنا بعد نتيجة تشغيل سير العمل، لذلك لا نصف الفحوص بأنها ناجحة قبل ظهور نتيجة GitHub Actions.
- ما زال اختبار المتصفح والهاتف، وفحص التفاعل مع جميع أنواع الأنشطة، والنشر الفعلي، غير منجز.



### تحديث إضافي — 2026-11-27

- يعرض المحرك الآن أمثلة الدرس من الحقلين `example` و`examples`، ويدعم أمثلة نصية أو كائنات تحتوي كلمات أو معادلات أو تركيزاً تعليمياً.
- يقبل الشرح `teacherScript` أو `explanation` عندما يكون نصاً أو مصفوفة نصوص/مقاطع.
- تمت إضافة نطق الأمثلة ضمن الشرح الصوتي.
- توسع المدقق ليتحقق من `choices` و`options`، ومن وجود الإجابات المرجعية للأنشطة العددية، ومن كون إجابات الترتيب تحتوي العناصر نفسها دون حذف أو إضافة.
- لم يتم التحقق بعد من نتيجة GitHub Actions لهذه التعديلات، ولم يتم تنفيذ اختبار متصفح فعلي؛ لذلك تظل هذه إصلاحات محفوظة في المصدر وليست إثباتاً على خلو التطبيق من الأخطاء.


### خطة الدروس اليومية — 2026-11-27

- أصبحت واجهة المادة تعرض خطة يومية بعدد الدروس الذي يحدده ولي الأمر في ملف الطالب (من 1 إلى 10).
- تختار الخطة الدروس غير المكتملة التالية وفق ترتيب فهرس المنهج، مع إبقاء جميع الدروس متاحة للمراجعة أو التعلم الإضافي.
- يظهر عدد الدروس المكتملة ضمن المادة المختارة فقط، ولا يخلط إنجاز القراءة بإنجاز الرياضيات.
- هذا تنظيم محلي للمنهج وليس تقويماً زمنياً صارماً؛ لا يزال التقدم محفوظاً على الجهاز ولا توجد مزامنة بين الأجهزة.

### منع خلط المواد وحماية تبديل ملفات الطلاب — 2026-11-27

- حُصر تحميل المحتوى المدعوم صراحةً في «القراءة/قراءتي» و«الرياضيات/رياضيات» للصف الأول؛ اختيار العلوم أو الإنجليزية أو مادة غير مدعومة يعيد حالة غير مدعومة ولا يوجّه إلى ملفات الرياضيات.
- أضيف رقم طلب لتحميل المادة، مع التحقق من أن ملف الطالب لم يتغير قبل رسم النتائج؛ يمنع هذا ظهور قائمة دروس طالب سابق إذا اكتمل التحميل بعد الانتقال إلى ملف طفل آخر.
- أزيل مؤشر التحميل السابق عند بدء طلب أحدث، وتُهمل نتائج الطلبات القديمة.
- هذا إصلاح في منطق المصدر؛ لم يُجر اختبار متصفح فعلي بعد، ويجب انتظار نتيجة GitHub Actions للتحقق الآلي.

### تحسين تسجيل الإنجاز ونتيجة الدرس — 2026-11-27

- إعادة درس مكتمل لم تعد تزيد عداد الدروس المكتملة مرة أخرى؛ يُحدّث العداد عند إكمال الدرس لأول مرة فقط لكل ملف طالب.
- تظهر للطالب نتيجة عدد الإجابات الصحيحة من مجموع الأسئلة التي قيّمها المحرك عند إنهاء الدرس، بينما الدرس الذي لا يحتوي أسئلة قابلة للتقييم يعرض رسالة إكمال دون اختلاق درجة.
- النتيجة المعروضة تكوينية ومحلية، وليست شهادة إتقان أو سجلاً سحابياً.

### تدقيق إضافي لمسارات الصفوف والمواد — 2026-11-27

- أصبح التحقق من الصف الأول مطابقاً لقيمة الصف كاملة بعد تطبيع الأرقام العربية والهندية والمسافات؛ لم يعد البحث الجزئي عن الرقم 1 كافياً لقبول صفوف أخرى مثل الصف العاشر.
- عند فتح مادة جديدة تُزال قائمة المادة السابقة أولاً، حتى لا تبقى دروس القراءة أو الرياضيات ظاهرة أسفل رسالة مادة غير مدعومة.
- تغيير ملف الطالب يبطل طلبات تحميل المواد السابقة حتى لو كان الملف الجديد يحمل المعرّف نفسه بعد إعادة فتحه.
- فحص ملفات المناهج الحالية شمل 20 ملف JSON و108 سجلات دروس. ظهرت أنواع أنشطة كثيرة غير مدعومة كتفاعل خاص؛ يعرضها المحرك كنشاط يحتاج تفاعلاً خاصاً ولا يمنحها تقييماً آلياً، بدلاً من تخمين إجابة أو نوع سؤال.
- لا تزال مراجعة الاختبارات على متصفح فعلي مطلوبة. نتائج هذا الفحص البنيوي لا تعادل اختباراً تشغيلياً كاملاً.

### إظهار الأنشطة غير المقيمة بدلاً من إسقاطها — 2026-11-27

- كان المحرك يعرض فقط الأنشطة التي تحتوي خيارات أو نوع إجابة محدداً؛ لذلك كانت أنشطة عملية مثل التمثيل بالمكعبات، التصنيف، الرسم البياني، وصف الصور وبعض تدريبات القراءة لا تظهر ضمن تسلسل الدرس.
- أصبح تسلسل الدرس يضم جميع عناصر activities وquiz. الأسئلة ذات الخيارات تُعرض كاختيار، والإجابات النصية أو العددية المفردة تُعرض كإدخال نصي، والإجابات المصفوفة تُعرض كحقول متتابعة.
- الأنشطة العملية أو الشفهية التي لا تملك إجابة آلية واضحة تظهر كتدريب مع زر متابعة، ولا تُحسب خطأً ولا تدخل في درجة التقييم.
- الدرجة أصبحت تُحسب من الأسئلة التي جرى تقييمها فعلياً فقط، مع فصلها عن الأنشطة التي أنجزها الطفل دون تصحيح آلي.
- لا تزال بعض أنواع الأنشطة المتخصصة تحتاج أدوات بصرية/تفاعلية حقيقية (مثل الرسم البياني، تحريك المجسمات، وضبط الساعة). النسخة الحالية تعرض تعليماتها ولا تدّعي أنها تنفذ تلك الأدوات.

#### جرد عناصر الأنشطة بعد توسيع العرض

- جرى فحص 20 ملفاً من ملفات الدروس الحالية: 108 سجلات دروس، و270 عنصراً في activities، و202 عنصراً في quiz.
- المحرك يعرض الآن عناصر activities وquiz في ترتيبها داخل الدرس. هذا الجرد بنيوي لعناصر JSON وليس دليلاً على أن كل نشاط صار تفاعلياً أو قابلاً للتصحيح آلياً.
- لم تُظهر أداة حالة الالتزام فحوص CI مرتبطة بآخر تعديل للمحرك؛ لذلك تبقى نتيجة التشغيل الآلي غير مؤكدة، كما لم يُنفذ اختبار متصفح أو هاتف.

### تساهل مضبوط في مطابقة الإجابات العربية — 2026-11-27

- أصبحت مطابقة الإجابات تتجاهل التشكيل والتطويل، وتوحّد صور الألف والهمزة والألف المقصورة، وتوحّد الأرقام العربية والهندية، والمسافات وحالة الأحرف اللاتينية.
- الهدف قبول الإجابة الصحيحة عند اختلافات الكتابة الشائعة، مع إبقاء مقارنة ترتيب العناصر بحسب ترتيبها الفعلي.

### إعادة سماع السؤال — 2026-11-27

- أضيف زر «استمع إلى السؤال» داخل كل سؤال، ويقرأ السؤال والخيارات المتاحة بصوت عربي من أصوات الجهاز.
- يحترم إعداد كتم الصوت والسرعة البطيئة، ويعرض رسالة بديلة إذا لم تتوفر واجهة النطق في المتصفح.
- يوقف النطق السابق عند الانتقال إلى سؤال جديد أو اعتماد الإجابة لتجنب تداخل المقاطع الصوتية.
- هذه الميزة تعتمد على Web Speech API ولا تستخدم خدمة صوت مدفوعة أو ترسل صوت الطفل إلى خادم.
- لم يتم اختبارها على متصفح فعلي أو هاتف Android بعد، كما لم تظهر نتيجة تشغيل GitHub Actions لهذا الالتزام حتى وقت التوثيق.

### تحسين نشاط ترتيب العناصر — 2026-11-27

- عند اختيار عنصر في أحد مواضع الترتيب، تُعطّل الخيارات المختارة في المواضع الأخرى لمنع تكرار العنصر نفسه في النشاط.
- يظل بإمكان الطفل تغيير اختياره، وتعود الخيارات التي لم تعد مستخدمة إلى الإتاحة.
- التحسين مناسب لقوائم الترتيب ذات العناصر المميزة؛ إذا احتوى نشاط مستقبلي على عناصر متطابقة مقصود تكرارها، فيلزم تطوير إدارة الكميات المتكررة قبل استخدام هذا النمط معها.
- لم يتم التحقق من السلوك في متصفح فعلي بعد.

### توضيح تعليمات الأنشطة العملية — 2026-11-27

- أضيف مولّد تعليمات عربية بحسب نوع النشاط عندما لا يحتوي سجل النشاط على سؤال أو تعليمات نصية جاهزة.
- يشمل ذلك أمثلة مثل تكوين العدد، العد للأمام والخلف، القفز على خط الأعداد، حقائق العائلة، تكوين العشرة، الأيام، الساعة، الكسور، ومخططات الصور.
- تُقرأ التعليمات الجديدة أيضاً من زر «استمع إلى السؤال».
- الأنشطة التي لا تملك إجابة مرجعية قابلة للتصحيح تبقى تدريباً عملياً ينجزه الطفل مع المعلم أو ولي الأمر ثم يتابع؛ لم نحولها إلى اختبارات آلية ولم نمنحها درجات افتراضية.
- هذه التعليمات صياغة مساعدة مشتقة من حقول بيانات النشاط، وليست اقتباساً حرفياً من الكتاب ولا بديلاً عن الأدوات البصرية المتخصصة مثل ساعة تفاعلية أو مخطط صور قابل للسحب.
- لم يُنفذ اختبار متصفح فعلي لهذا التعديل بعد.


### إصلاح تكرار العناصر وتقوية مدقق الملفات — 2026-11-27

- عُدّل نشاط ترتيب العناصر ليعتمد على رقم موضع العنصر في القائمة بدلاً من نصه وحده؛ وبذلك يمكن التعامل مع عناصر متطابقة الاسم إذا كان تكرارها مقصوداً، مع منع اختيار النسخة نفسها مرتين.
- أصبح مدقق المنهج يكتشف بنية غير صالحة في حقول الوحدات والفصول وروابط ملفات الدروس وسجلات الدروس، ويصدر أخطاء مفهومة بدلاً من التعطل عند بعض البيانات المشوهة.
- أُطلقت عملية GitHub Actions تلقائياً بعد التحديث الأخير، وكانت لا تزال قيد التنفيذ عند تسجيل هذه الملاحظة. لا تُعد نتيجة الفحص ناجحة قبل ظهور حالة نهائية.
- لم يُنفذ اختبار تفاعل على متصفح أو هاتف، ولم يحدث أي نشر.
